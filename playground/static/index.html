Sentinel playground

Paste a prompt and see whether an open-source prompt-injection filter would block it, and which layer caught it. This is a demo of ai-sentinel, not a security guarantee. Text you type is checked and then discarded; it is not stored.

The default setup stops classic phrases; a pretrained public classifier catches much more, including reworded and other-language attacks, at the cost of some false alarms.

These are documents an attacker might slip into a knowledge base. Each paragraph is checked separately, as a RAG system would before giving it to a model.

Measured results, method and limits: sentinel-eval. On a small blind test (now used up; 2026-11-14/15) the default caught about 1 in 10 attacks, the ProtectAI mode 73% and the deepset mode 93%, with 8-12% of harmless prompts wrongly blocked.
